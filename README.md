WORLD SPOTTER

Lik to the page - [https://aadyantbharticodes.github.io/WorldSpoter]

WorldSpotter use Mapillary API to load images.
1. Go to Mapillary Developer Dashboard(https://mapillary.com)
2. Make a acoount and then fill the application to create a App.
3. Click view next to your app and copy the Client Token(MLY|...).

To run locally clone the github repo and add your API in config.js.

Then launch the game via Live server in VS Code to run locally on your browser.
